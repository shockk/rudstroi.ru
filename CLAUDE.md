# CLAUDE.md

- Язык общения, текстов сайта и документации: русский.
- Главный рабочий документ: `docs/PROJECT.md`. Перед работой прочитай его. Новые решения записывай в «Журнал решений», ответы — в «Открытые вопросы», прогресс отмечай в «Плане работ».
- Сайт: Next.js (App Router, TypeScript) с сервером, хостинг — Timeweb Cloud App Platform (backend-приложение с SSR, `npm run build` → `npm start`, автодеплой из `main`).
- Страницы по возможности пререндерятся при сборке (`generateStaticParams`, без динамических данных). Серверный код — только обработчики в `app/api/` (заявки).
- Цены на сайте не показываем нигде, даже «от…». Формы расчёта только собирают данные и отправляют заявку.
- Контент (услуги, техника, материалы, контакты) хранится в `data/*.ts`; страницы генерируются из данных, тексты в компонентах не хардкодим.
- Стили: только CSS Modules (`Component.module.css` рядом с компонентом) и CSS-переменные из `app/globals.css`. Без Tailwind, CSS-in-JS и UI-библиотек. Цвета не хардкодим в модулях, берём из переменных.
- Секреты (токен Telegram-бота, ID чата) — только в переменных окружения: локально `.env.local`, на сервере — в панели Timeweb. Никогда не используем их в клиентских компонентах и не даём им префикс `NEXT_PUBLIC_`.
