## 1. Компания и услуги

Компания занимается благоустройством территорий, арендой спецтехники, поставкой инертных материалов и зимним содержанием.

Услуги делятся на три направления. Клиент обычно приходит за одним из них:

| Направление | Услуги | Кто клиент | Сезон |
|---|---|---|---|
| **Благоустройство под ключ** | асфальтирование, асфальтная крошка, тротуарная плитка (продажа и укладка), газон, планировка участка | частники, коттеджные посёлки, УК/ТСЖ, магазины | апрель–октябрь |
| **Техника и материалы** | аренда спецтехники, инертные материалы (песок, щебень, ПГС, грунт), вывоз грунта | строители, прорабы, частники на стройке | круглый год |
| **Зима** | уборка снега, вывоз снега | УК, ТСЖ, ТЦ, склады, посёлки | ноябрь–март |

### Ключевая идея
**Сайт перестраивает главную под сезон.** Зимой на первом экране снег, договор на зиму и «приедем сегодня». С апреля там асфальт и плитка. Меню и остальные страницы при этом не меняются.

## 2. Структура сайта

- **Главная**: сезонный первый экран, 3 направления плитками, цифры (лет работы, единиц техники, м² уложено), примеры работ, форма заявки.
- **Посадочные страницы услуг** — по одной на услугу (один поисковый запрос — одна страница):
  - `/uslugi/asfaltirovanie/`
  - `/uslugi/asfaltnaya-kroshka/`
  - `/uslugi/trotuarnaya-plitka/` (укладка + продажа)
  - `/uslugi/gazon/`
  - `/uslugi/planirovka-uchastka/`
  - `/uslugi/vyvoz-grunta/`
  - `/uslugi/uborka-snega/`
  - `/uslugi/vyvoz-snega/`
- **Спецтехника** `/tehnika/`: каталог парка, карточки (фото, характеристики, минимальный заказ, кнопка «Узнать цену» — открывает заявку с выбранной техникой).
- **Материалы** `/materialy/`: список материалов (фракции, применение), форма «рассчитать доставку».
- **Наши работы** `/raboty/`: фото «до и после», объект, площадь, сроки.
- Страницы «Цены» нет: цены сообщаем по телефону.
- Отдельной страницы «Юрлицам» нет: основной клиент — частник. Если обратится юрлицо, на странице контактов будет строка «работаем с организациями по договору».
- **Контакты** `/kontakty/`: карта, зона выезда, реквизиты.
- **Идея: гео-страницы.** Страницы под связку «услуга + город» для ключевых услуг, например `/krasnogorsk/asfaltirovanie/`, `/istra/vyvoz-snega/`. Это даёт локальный поиск по запросам вида «асфальтирование Истра». Генерируются из данных и не должны повторять друг друга дословно: в каждой свои объекты в этом городе, сроки выезда, отзывы.
- **Политика обработки ПДн** `/privacy/`: обязательна из-за формы (152-ФЗ).

## 3. Что приносит заявки

1. **Формы расчёта** (вместо калькуляторов с ценой). Клиент пошагово заполняет параметры, цену на сайте **не показываем**, на выходе — заявка, менеджер перезванивает с расчётом:
   - благоустройство: вид работ, площадь, текущее покрытие, город, фото участка;
   - материалы: материал, объём, адрес доставки, дата;
   - техника: вид техники, срок аренды, адрес объекта;
   - снег: территория, площадь, разово или по договору на сезон.
2. **Мгновенная связь**: телефон всегда на виду в шапке; WhatsApp, Telegram, MAX; форма «пришлите фото участка — посчитаем».
3. **Бесплатный выезд замерщика** — основное предложение для благоустройства.
4. **Доверие**: фото своей техники и своих объектов (не стоковые), гарантия на укладку, работа по договору, отзывы с Яндекс Карт.

## 3а. Фирменный стиль

Палитра **«Зелёный и охра»**: спокойная, «домашняя», хорошо ложится на фото садов, газонов и участков. Ориентир — частный клиент, надёжность, уверенность.

| Роль | Переменная | Цвет | Где используется |
|---|---|---|---|
| Основной | `--primary` | `#1F3B2D` | шапка, заголовки, блок «Почему мы» |
| Глубокий | `--deep` | `#13271D` | верхняя строка, подвал, затемнение фото |
| Акцент | `--accent` | `#D9A441` | кнопки, вторая часть логотипа, метки |
| Акцент (наведение) | `--accent-hover` | `#C48F2C` | наведение на кнопки, надписи над заголовками |
| Текст на акценте | `--on-accent` | `#1A2A1F` | текст кнопок |
| Фон страницы | `--bg` | `#F6F4EE` | общий фон |
| Карточки | `--surface` | `#FFFFFF` | карточки, форма |
| Текст | `--text` | `#1C2A21` | основной текст |
| Второстепенный текст | `--muted` | `#5B6A5F` | описания, подписи |
| Линии | `--line` | `#E3DFD3` | рамки, разделители |
| Мягкий фон | `--soft` | `#ECE8DC` | фон блока формы, выбранные опции |

- Шрифт: **Onest** (Google Fonts, хорошая кириллица), начертания 400–800.
- Логотип: «РУД» белым или `--primary`, «СТРОЙ» цветом `--accent`, жирность 800, разрядка 0.03em.
- Макет с примерами: `design/palettes.html#p3`, скриншот `design/screenshots/palette-3.png`.
- Зимний блок и фото техники на этой палитре смотрятся слабее — подбирать для них фото с тёплым светом.

## 4. Техническое решение

### Стек
- **Next.js** (App Router, TypeScript) с сервером (SSR), Node 22.
- **CSS Modules** (`*.module.css` рядом с компонентом), без Tailwind и CSS-in-JS. Общие цвета, отступы и шрифты — CSS-переменные в `app/globals.css`.
- Контент лежит в файлах `data/*.ts`: услуги, техника, материалы. Страницы генерируются из них.
- Страницы по возможности статические (пререндер при сборке через `generateStaticParams`); серверный код — только обработчик заявок.

### Хостинг: Timeweb Cloud App Platform (backend-приложение, SSR)
```
GitHub (push в main) ──► Timeweb App Platform: npm ci → npm run build → npm start
                          ├─► страницы сайта (пререндер + SSR)
                          └─► POST /api/lead ──► Telegram-бот (+ почта)
```
- Приложение создаётся как **Next.js с включённым SSR** (backend-режим). Режим нельзя переключить после создания — только пересоздать приложение.
- Плата фиксированная за конфигурацию сервера (цена — в панели при создании), а не за запросы.
- Автодеплой при push в GitHub, бесплатный SSL Let's Encrypt на свой домен (A-запись у регистратора).
- Секреты (токен Telegram-бота, ID чата) — в переменных окружения приложения в панели Timeweb; в репозиторий не попадают, локально — в `.env.local`.
- Серверы в РФ — требования **152-ФЗ** к хранению персональных данных выполняются.
- **152-ФЗ и Telegram.** Передача имени и телефона в Telegram — трансграничная передача; формулировку в политике ПДн проверить с юристом.
- Отвергнутые варианты: статика в S3 + Yandex Cloud Function (дешевле, но два провайдера); Frontend App (оплата за запросы, нет серверного кода).

### Форма заявки
- Поля: имя, телефон (обязательно), услуга, адрес или район, комментарий, фото (опционально), согласие на обработку ПДн.
- Токен Telegram-бота **только** в обработчике заявок на сервере, на клиенте его нет.
- Защита от спама: honeypot-поле и ограничение частоты запросов в обработчике. Капча по необходимости (Yandex SmartCaptcha).

### SEO
- Уникальные title и description на каждую страницу.
- `sitemap.xml`, `robots.txt`.
- Микроразметка: `LocalBusiness`, `Service`, `FAQPage`, `BreadcrumbList`.
- Яндекс Вебмастер, Яндекс Бизнес (карточка организации), Google Search Console.
- Аналитика: Яндекс Метрика с целями «отправил форму», «нажал телефон», «нажал мессенджер».
